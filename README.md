# LayoutEase

*Drag. Adjust. Save.*

**快速选中、拖动和调整网页组件，减少查找代码与反复调用 AI 的时间。**

LayoutEase 是一款面向已有 HTML 页面的 Windows 可视化编辑工具。打开本地项目，在预览中选中要调整的文字、图片或可识别的 SVG 组件，直接拖动位置、调整大小和样式，再保存回项目。

常见的位置、尺寸、文字和图片修改，可以直接在画面上完成，不用先在源码中寻找对应元素，也不必每次都借助 AI。适合在已有页面上快速试调、查看效果、继续修改，提高日常调整效率。

例如：把按钮向右挪一点、缩小一张图片、修改提示文字，或暂停互动过程后调整此时出现的对象。

## 详细功能

### 1. 直接拖动组件，快速调整位置

- 在页面预览中点击选中对象，直接拖动到需要的位置。
- 调整时即时查看画面效果，支持对齐辅助。
- 常见的“挪一点、放大一些、缩小一些”，可以在画面中完成。

### 2. 调整尺寸与样式

- 拖动缩放控制点，或在属性面板输入宽度和高度。
- 按需要独立调整宽高，或使用等比缩放。
- 修改支持元素的字号、文字颜色、显示方式及内外间距。

### 3. 修改文字与图片

- 选中可编辑的网页文字，直接修改内容。
- 从本地添加图片，或替换已有图片、支持的背景图片。
- 调整图片的位置和大小，删除不需要的可选元素。
- 图片中已经合成的文字仍属于图片，需要更换图片或修改原素材。

### 4. 独立编辑 SVG 中的对象

- 对具有可识别图层的 SVG，选中其中的组件，分别移动和缩放。
- 支持使用图层标识、SVG 组 ID 等方式定位对象。
- 具有组件结构的动态卡片，可以把图片、数字和装饰作为整体操作。
- 具体可编辑范围取决于 SVG 自身的图层结构；合成图片不会自动拆成独立对象。

### 5. 多选、框选与组合移动

- 框选多个对象，或按住 Shift 追加选择。
- 将选中的对象组成一组，一起调整位置。
- 适合移动一整组按钮、图文说明或成组装饰，减少逐个拖动。

### 6. 暂停互动过程，编辑当前画面

- 在“测试”模式操作原页面，进入需要调整的状态。
- 点击“立即定格”，暂停当前画面并切换到编辑。
- 调整动态出现的提示、图片和其他可识别元素。
- 切回测试模式，继续查看互动效果。

### 7. 设置修改影响哪些画面与页面

- 对可识别的场景，选择只修改当前画面、指定画面或全部画面。
- 分别设置位置、尺寸和其他样式的修改范围。
- 设置支持对象的出现范围，控制在哪些画面显示。
- 将支持的图片或组合应用到同一项目中选定的 HTML 页面，先查看执行计划再应用。
- 跨画面同步需要能唯一识别对应组件，不能仅凭相似位置自动匹配。

### 8. 查看不同屏幕尺寸下的效果

- 提供电脑、平板、手机横屏和竖屏预览。
- 支持自定义预览宽高与画布缩放。
- 按支持的设备范围保存样式，检查不同尺寸下的布局。
- 预览用于辅助调整，实际发布前仍需检查目标设备和浏览器。

### 9. 配置常见点击交互

- 配置页面跳转和返回。
- 配置目标元素的显示、隐藏和显示状态切换。
- 配置样式类切换，以及媒体播放和暂停。
- 适合基础按钮行为，复杂业务逻辑仍需要修改代码。

### 10. 保存、撤销与版本恢复

- 点击“保存”，把修改写回本地项目。
- 使用撤销和重做，回退或恢复编辑操作。
- 创建命名版本，保存阶段成果。
- 从项目版本快照恢复，便于对比和回退。

### 11. 管理已有本地项目

- 打开项目文件夹或 HTML 文件，无需上传到编辑器服务器。
- 在同一项目内切换 HTML 页面。
- 从项目列表重新打开最近使用的项目。
- 项目文件被外部工具修改时，可根据更新提示读取最新内容。

### 12. 可选的 AI 辅助修改（实验性）

- 配置自己的 API 服务和模型，用文字描述修改需求。
- 选择提供给 AI 的上下文文件，查看返回的代码差异。
- 先在隔离预览中查看方案，再决定是否应用。
- AI 是可选功能，常规拖动、文字、图片和样式调整无需配置 API。

## 适用场景

- **普通静态网页：** 微调已有 HTML/CSS/JavaScript 页面，例如介绍页、活动页和展示页中的文字、图片与布局。
- **互动演示与课件：** 在运行过程中暂停画面，调整动态内容，并在可识别的场景间同步修改。课件是当前验证较充分的使用场景。
- **前端开发中的视觉微调：** 对能直接运行的 HTML 页面，快速尝试位置、尺寸和样式变化，减少反复查找元素与修改代码的步骤。

**关于 React、Vue 等工程：** 当前不能可靠地把可视化操作写回 `.tsx`、`.jsx` 或 `.vue` 组件源码。构建后的 HTML 与静态资源在可识别的情况下可以尝试调整，但重新构建可能覆盖这些修改，也可能被框架重新渲染覆盖。因此，目前更适合已有 HTML 页面的可视化调整，不能替代完整的前端工程开发环境。

## 下载与开始使用

当前提供 **Windows x64** 安装包。

1. 在 [Releases](https://github.com/LYX-shb/layoutease/releases/latest) 下载名称以 `Setup.exe` 结尾的安装包并安装。
2. 打开编辑器，点击“浏览文件夹”，选择包含入口 HTML 的项目；也可以从文件菜单打开 HTML 文件。
3. 在“编辑”模式中选中元素，通过拖动或右侧属性面板调整。
4. 需要操作页面时切换到“测试”；到达目标画面后点击“立即定格”，继续编辑。
5. 点击“保存”写回项目。需要保留阶段成果时，可创建命名版本。

更新前请保存修改并退出旧版，再运行新安装包。当前安装包尚未做代码签名，Windows 可能显示未知发布者提示。

## 使用范围与限制

- **适合已有的 HTML/CSS/JavaScript 项目。** 更适合可在本地直接运行的页面，以及有清晰 DOM 或 SVG 图层的互动内容。
- **多画面同步需要可靠的对应关系。** 不同画面中的对象需要可识别的状态与组件标识；无法唯一对应时，编辑器会限制同步，并非任意网页都能自动识别全部组件。
- **图片内的内容仍属于图片。** 已经合成在位图中的文字不能直接当作网页文字修改；Canvas、视频或整体位图内部也不能按普通 DOM 元素拆分编辑。
- **保存会修改项目文件。** 保存结果可能包含编辑器追加的样式、布局数据和运行脚本。建议先使用项目副本体验，重要修改前创建版本。
- **设备预览用于辅助检查。** 它不能代替真实设备、浏览器或微信等宿主环境的验证。
- **AI 功能需要自行配置服务。** 模型兼容性和生成结果取决于所选服务；该功能仍处于实验阶段。

当前不提供直接导入 `.fig`、从任意网页无损生成源代码，或完整替代专业设计工具的能力。

## 本地数据与 AI

常规编辑在本机进行，项目版本和应用设置保存在本地。AI API 密钥使用 Electron 的系统安全存储能力加密保存；启用 AI 请求时，会把所选上下文和修改需求发送给配置的 API 服务。

页面自身的脚本仍可能访问其原有网络资源，请使用来源可信的项目。

## 从源码运行

技术栈：**Electron + React + TypeScript + Vite**。

安装 Node.js、npm 和 Git 后执行：

```powershell
git clone https://github.com/LYX-shb/layoutease.git
cd layoutease
npm ci
npm run dev
```

开发启动需要完整安装依赖。普通用户直接下载安装包即可。

仓库内的 `examples/theme-unit/` 提供简单示例，可用于了解打开、编辑和保存流程。

## 开发命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动桌面开发环境。 |
| `npm run typecheck` | 检查界面代码和 Vite 配置的 TypeScript 类型。 |
| `npm test` | 运行仓库内的自动化测试。 |
| `npm run build` | 检查类型并构建界面资源。 |
| `npm run package:win` | 构建 Windows 安装包。 |

`npm run preview` 仅预览构建后的界面资源，完整文件编辑功能需要桌面环境。

安装包输出到 `release/`。依赖、构建产物、用户项目和本机配置不提交到源码仓库。

## 仓库结构

```text

scripts/     开发启动、专项检查与维护脚本
examples/    示例 HTML 项目
build/       应用图标等打包资源
```
