# 产品需求与范围

## 1. 产品定位

这是一个运行在 Windows 上的“交互学习网页编辑器”。它编辑和运行真实的 HTML/CSS/JavaScript 学习网页，而不是 PPT 或幻灯片。

用户可以导入一个主题单元项目，在可视化画布中微调界面，并在需要时使用自己接入的 AI 编写复杂交互逻辑。

## 2. 已确认的用户目标

- 快速调整标题、正文、图片、按钮等元素的位置和字体大小。
- 替换文字、图片、图标、背景等素材。
- 在电脑、平板和手机视口中预览和调整；手机方向选择竖屏或横屏其中一种。
- 支持一个界面，也能打开已有的多个 HTML 页面进行编辑。
- 修改页面跳转、弹窗、答题、计分、音视频和其他 JavaScript 逻辑。
- 修改过程可预览、可撤销、可重做，并能恢复历史版本。
- AI 使用用户自己的 API，不在软件中内置默认密钥。

## 3. 第一版范围

### 必须完成

1. Windows 桌面应用外壳。
2. 打开一个本地主题单元项目，识别入口 HTML、CSS、JS 和 `assets` 素材目录。
3. 安全预览真实网页，并支持基础刷新。
4. 识别带有 `data-editor-id` 的元素。
5. 选中元素后调整字体大小、文字内容、位置、宽高、颜色和常用间距。
6. 替换图片、图标和背景素材，并更新引用。
7. 电脑、平板、手机竖屏、手机横屏四种预设视口，其中手机方向二选一。
8. 撤销、重做、保存前备份和版本恢复。
9. 保留原 HTML/CSS/JS 结构，禁止无确认的整项目重写。

### 后续阶段

- 已有多页面项目的页面切换和页面树。
- 基础交互配置：跳转、返回、弹窗、显示隐藏、媒体控制。
- 用户 API 配置和 AI 代码助手。
- AI 生成代码差异、预览、应用和失败回滚。
- 更复杂的学习状态、分支逻辑和调试辅助。

## 4. 新建项目原则

新建项目默认创建一个主题单元和一个页面，不预先要求用户设计课程目录。用户需要时再添加页面。打开已有项目时，软件可以识别其中的多个 HTML 页面，但多页面能力不应阻塞单页面编辑。

手机方向是主题单元的明确配置项。用户选择“手机竖屏”或“手机横屏”后，预览和后续适配以该方向为准。

## 5. 典型用户流程

### 手动微调

打开项目 → 进入页面 → 选中元素 → 修改属性或拖拽 → 预览 → 确认保存 → 生成版本。

### AI 复杂逻辑

打开项目 → 配置用户 API → 描述功能 → AI 读取必要代码 → 生成补丁和说明 → 运行预览 → 用户查看差异并测试 → 确认应用或撤销。

## 6. 非目标

第一版不追求兼容所有前端框架、不自动重写任意未知代码、不做 PPT 导入、不做在线协作、不做课程内容管理后台、不做自动发布平台。
