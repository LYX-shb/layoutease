## 首页开场

**快速选中、拖动和调整网页组件，减少查找代码与反复调用 AI 的时间。**

LayoutEase 是一款面向已有 HTML 页面的 Windows 可视化编辑工具。打开本地项目，在预览中选中要调整的文字、图片或可识别的 SVG 组件，直接拖动位置、调整大小和样式，再保存回项目。

常见的位置、尺寸、文字和图片修改，可以直接在画面上完成，不用先在源码中寻找对应元素，也不必每次都借助 AI。适合在已有页面上快速试调、查看效果、继续修改，提高日常调整效率。

## 功能概览

1. **可视化拖动：** 选中对象后直接调整位置，即时查看效果。
2. **尺寸与样式：** 调整宽高、缩放比例、字号、颜色和间距。
3. **文字与图片：** 修改网页文字，添加或替换本地图片。
4. **SVG 组件：** 对可识别的图层独立选择、移动和缩放。
5. **多选与组合：** 框选对象或追加选择，把一组元素一起移动。
6. **互动定格：** 操作页面后暂停在目标画面，编辑动态出现的元素。
7. **修改范围：** 对可识别的场景选择当前、指定或全部画面，并支持选定页面的素材或组合同步。
8. **多尺寸预览：** 查看电脑、平板、手机横竖屏与自定义尺寸的效果。
9. **基础交互：** 配置跳转、显示隐藏、样式类切换和媒体播放暂停。
10. **保存与恢复：** 保存回项目，撤销、重做并创建可恢复的项目版本。
11. **本地项目：** 打开文件夹或 HTML，在项目内切换页面、重新打开最近项目。
12. **可选 AI：** 自带 API、选择上下文、查看代码差异和隔离预览后应用方案。

每项的详细操作与适用条件见 [README 功能介绍](../README.md#详细功能)。

## 适用场景说明

普通 HTML/CSS/JavaScript 网页、互动演示和课件都可以使用，重点是已有页面的视觉微调。课件是当前验证较充分的场景。

React、Vue 等工程当前不支持把可视化操作可靠写回组件源码；修改构建产物可能被重新构建或框架重新渲染覆盖。对外介绍应保留这一边界，不宣传为适用于全部前端工程的开发环境。

## v0.1.10 发布说明

### 标题

v0.1.10 · 修复 SVG 组件选择与拖动

### 正文

本项目现名为 **LayoutEase**。此版本为更名前发布的安装包，文件名与包内显示名仍保留原名。

修复部分 SVG 页面点击对象后选中整幅画面、无法独立移动的问题。

- 支持通过 SVG 组 ID 识别独立组件，卡片中的图片、数字与装饰保持为完整对象。
- 支持这类组件的拖动、框选、缩放、撤销与重做，以及保存后重新打开。
- 保留小型 SVG 图标的整体选择，并包含此前的多画面位置与尺寸同步修复。

发布前已完成 70 项自动化测试、19 项元素选择回归和 9 项 SVG 组件编辑检查。

Windows x64 用户请下载 `Theme-Unit-Editor-0.1.10-Setup.exe`。更新前保存修改并退出旧版，再运行安装程序。当前安装包尚未代码签名。
