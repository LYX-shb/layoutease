# 0.1.2 图片选中修复

原有逻辑临时恢复禁止点击的图片后，只取最上方命中元素。透明按钮仍会挡住图片，后续祖先背景回退还可能误选整张场景背景。该路径在“第5讲 还要2”的进度板和动态福字上已复现，并非单纯修改界面即可解决。

新逻辑使用浏览器实际叠层命中顺序，跳过空白透明交互热区及其半透明高亮，保留可见文字和不透明遮挡。图片、CSS 背景、SVG 整体及 canvas 元素支持恢复命中；旋转和裁切使用浏览器命中结果，隐藏元素排除。临时 pointer-events 改动在 finally 中还原，不写回课件。Alt + 单击可以循环选择同一点的重叠图层。交互目标拾取和测试模式继续使用原网页控制区域。

验证命令（需要先构建前端，再用 Electron 运行）：

```powershell
node_modules\electron\dist\electron.exe scripts\check-image-selection.cjs "--course=D:\第5讲 还要2"
```

检查脚本先将课件复制到系统临时目录，并使用独立用户配置目录。22 项检查通过，包括真实鼠标事件、透明热区、动态福字、算式槽背景与内容、数字、提示图、等号、重叠切换、图片尺寸保存和重新生成、CSS 背景、SVG、旋转、裁切、隐藏与不透明遮挡，以及原生交互保留。既有 23 项自动化测试及 TypeScript / Vite 构建通过。

合并绘制在一张图片内的多个图案仍是一项图片资源；canvas 内部图形和 SVG 子图形也不会自动拆分成独立素材。此修复不代表所有网页结构已经验收。
