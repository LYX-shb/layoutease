# 0.1.8 SVG 组件跨画面几何同步

## 问题与原因

“10.1”课件在六个画面中为同一图片组件导出了不同的 `data-node` 编号。0.1.7 的范围设置仅保存当前编号的偏好，以及已有的样式修改；没有发生拖动或缩放时，保存数据中只有 preferences、没有实际位置或尺寸。设置为所有或六个指定画面，仍无法识别其他编号，也不能覆盖各画面原有坐标差异。

## 修复

- 对明确提供的 `FIGMA.scenes` 列表，用图像引用和矢量内容识别对应组件；重复图像再按剪切和绘制结构核对，无法唯一匹配时拒绝跨画面固定，并给出原因。
- 选择位置或尺寸的画面范围时立即捕获当前实际外框，即使没有先拖动也有可保存的几何记录。两个范围保持独立。
- 新的 `svgPins` 记录包含对应节点、画面范围、设备范围，以及相对于 SVG 画布的实际位置和尺寸。
- 使用独立 SVG 包装组施加可还原的几何变换，保留课件原有图形、父变换和已有布局运行脚本。新运行层随 HTML 保存，独立网页不需要编辑器桥接。
- 同步组件仍能继续拖动、缩放和撤销；新的几何值作用于所选范围。缩小为指定画面后，其余画面恢复自身布局。
- 为旧版只有偏好的设置提供“将当前位置／尺寸固定到所选画面”操作。旧数据没有记录想固定的实际数值，因此不在打开课件时猜测并改写。

## 验证

64 项 Node 测试、TypeScript 编译和 Vite 构建通过。课件副本的 19 项选择回归检查，以及 7 项同步检查通过：不经拖动直接固定、六画面相同外框、保存重开保留旧运行器、继续拖动和缩放、撤销、指定画面隔离、独立 HTML 六画面同步。

验证复制 `D:/10.1` 到临时目录，未改动用户课件。安装更新本身不会补写旧课件的固定记录；需要选中目标组件，在位置、尺寸页分别执行固定并保存。
