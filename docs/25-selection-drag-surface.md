# 选区拖动操作修复（2026-10-21）

- 取消每次移动前启用、移动后锁定的操作门槛。选中素材后可直接拖动，上方拖动条也直接启动同一套指针手势。
- 单选和多选都使用可接收指针的选框。选框向外扩展10 CSS像素；当前选区内的普通拖动保持原选择，避免容器内的子组件抢走选择。
- 双击进入内部素材，Alt点击切换重叠图层，Shift点击继续增减多选成员。拖动条最小180×44，独立宽度、高度和角点控制点24×24。
- 选框范围包含图片、SVG和Canvas子图形实际外框，处理子图形相对容器偏移后仍难以拖到的情况。
- 单独拖动被强制组合位置约束的成员，或包含此类成员的容器时，在首次发生实际位移时保留其当前内外位置并建立对应画面例外，避免被组合锚点拉回。未发生移动的点击不创建该例外；整组移动仍保留组合规则。沿用完整布局快照撤销与保存。
- 对公开CoursewareDebug.getState().name的课件，补充独立的画面标记适配器，读取真实业务状态，使默认当前画面修改可用。保存时适配器也写入HTML；不推测未知课件状态，不覆盖课件自有标记。

本次没有改写课件文件或素材。完成CJS/内嵌桥接语法编译、TypeScript编译、Vite构建；未运行测试套件，未做真机拖动验收。
