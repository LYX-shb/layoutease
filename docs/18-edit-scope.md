# 修改应用范围

## 使用方法

选中素材，在右侧“样式 → 修改应用范围”中选择要设置的属性：位置、尺寸或其他样式。这三类属性分别记忆范围。

- **当前画面**：只修改当前交互状态，默认使用此项。
- **指定画面**：勾选需要一起调整的画面。当前画面始终包含在内。
- **全部画面（当前网页）**：该素材在当前 HTML 中的所有状态共用调整，也覆盖之后出现的状态。

蜜蜂课件可在填写算式时选中蜜蜂，选择“位置 → 指定画面 → 关联全部作答画面”，将填写算式、答错反馈、答对反馈关联，再拖动蜜蜂。可以先拖动再更改范围，已有位置调整会一起同步。

不同蜜蜂根据所属组和序号分别定位，不会因为使用同一张图片而一起移动。只有选中的素材会同步。

## 保存与刷新

修改后点击工具栏“保存”，再刷新预览。范围偏好和布局一起写入当前 HTML，重新打开或导出后仍可生效。保存前自动创建完整项目快照。范围切换、拖动和缩放均可撤销、重做。

第一次更新此功能涉及桌面编辑器的主进程和保存接口，需要关闭后重开新版编辑器。之后日常修改课件时，保存并刷新预览即可。

## 范围规则

- 多个画面指同一 HTML 的交互状态；不会修改项目中其他 HTML。
- 当前设备的范围设置独立；电脑默认样式可被手机、平板的独立样式覆盖，沿用现有宽度区间。
- 位置以素材的原始布局为基础保留偏移，保留原有的旋转、翻转和动画。
- 页面脚本重新排布或重新生成同一素材后，仍会应用已保存调整。
- 指定范围缩小时，取消勾选的状态恢复其独立布局。
- 页面有 `CourseConfig.layouts` 时列出所有配置状态；其他页面列出本次预览已经出现的状态。没有状态标识的页面只按当前网页编辑。
- 当前版本同步位置、尺寸和面板中的其他样式；文字、图片替换和交互配置继续沿用原有保存方式。

## 检查

`tests/edit-scopes.test.cjs` 覆盖实际预览桥接代码的拖动、指定范围与全局范围、范围缩小、属性分组、节点重建、撤销重做、独立 HTML 保存、设备隔离和旧样式迁移。

`tests/acceptance.test.cjs` 覆盖保存接口、重复保存、自动版本备份、无效数据和越界路径。
