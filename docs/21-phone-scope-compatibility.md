# 手机预览与手机实际网页一致性修复

## 已复现的问题

P70 预设原先使用 378 × 763 的估算视口，保存时归入宽度不超过 500px 的范围。实际手机或微信如果使用 504px、844px 等视口，就不匹配该保存范围。用同一份课件代码已复现：378px 显示修改后的提示条，504px 和 844px 恢复 800 × 72 的初始尺寸。

该问题与网页是否上传同一版本是两个独立问题；未读取线上文件时，不能据此断定用户上传有误，也不能声称真实手机已验证。

## 修复

- 手机预设、P70 预设和短边不超过 600px 的自定义手机预览，保存到 `phone` 手机通用范围。
- 独立网页根据移动 UA、UA Client Hints、视口和触控信息判断手机，横竖屏共用手机调整，不再仅依赖 500px 分界。
- 默认电脑样式、旧宽度区间记录仍保留。明确保存的手机通用属性优先于旧宽度记录；没有手机通用覆盖的属性继续沿用旧配置。
- 为旧内核补充 `:is()` 选择器匹配回退；不支持 CSS 独立 `translate` 时使用等效的 transform 位移并保留素材原有 transform。
- P70 下拉选项标明“尺寸模拟”，面板说明它使用电脑浏览器内核，不宣称连接真机。
- 保存后的独立 HTML 标记 `data-editor-runtime-version="phone-v2"`，无需依赖编辑器安装目录运行。
