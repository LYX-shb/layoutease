# 第二版范围与交付标准

更新时间：2026-10-05

当前进度：第二版 A 阶段已完成第一批实现，并补齐按钮内嵌图片替换、动态复合元素文字保留和稳定规则清理；第二版 B 已完成基础交互配置第一批（跳转、返回、显示/隐藏、切换样式、播放/暂停）；第二版 C 已完成完整项目快照、恢复前备份、版本说明和删除确认；D 尚未开始。A、B、C 正在等待用真实主题单元做界面验收。

第二版建立在第一版基础编辑已经可用的前提上，目标是让编辑器能够处理真实的 Vue/React/原生 JavaScript 交互课件，并帮助用户编写复杂交互逻辑。第二版不重新设计课程目录，也不做 PPT 编辑。

## 一、第二版目标

用户可以打开一个真实的交互课件项目，编辑动态生成的界面元素，配置常见页面交互，并通过自己接入的 API 让 AI 生成 JavaScript 修改。所有 AI 修改都必须经过差异预览、运行测试和用户确认。

## 二、第二版必须完成的功能

### 1. 动态元素完整编辑

- 支持 Vue、React 和原生 JavaScript 运行后生成的常见元素。
- 动态元素可以修改文字、字号、颜色、宽高、间距、位置和显示状态。
- 动态元素可以替换 `img` 的图片、按钮图片和 CSS `background-image`。
- 动态元素重新加载后仍能通过稳定选择器定位，不依赖本次运行生成的临时编号。
- 选择元素时显示元素来源类型：HTML、CSS 或 JavaScript 动态生成。

**验收操作：**在动态生成的标题、图片按钮、卡片和弹窗上分别修改一个属性，刷新页面后修改仍然存在，原有点击逻辑仍然正常。

### 2. 页面和交互状态编辑

- 多页面之间可以通过页面列表切换，也能识别网页自身的下一页、返回和弹窗。
- 支持查看当前页面的简单状态，例如当前步骤、选中项、是否显示。
- 支持配置常见动作：跳转页面、返回、显示/隐藏、切换样式、播放/暂停媒体。
- 测试模式可以运行原有交互；编辑模式不会误触发原有交互。
- 修改当前页面的交互后，只写入当前页面或明确指定的 JS 文件。

**验收操作：**配置一个按钮跳转、一个元素显示/隐藏和一个弹窗，测试运行、刷新和重新打开后结果一致。

### 3. 用户自带 API 的 AI 代码助手

- 用户可以填写 API 地址、API 密钥和模型名称。
- 支持 OpenAI 兼容的 Chat Completions 或 Responses 接口格式。
- 密钥保存在本机安全存储中，不写入项目文件、浏览器 localStorage 或普通日志。
- 用户可以选择发送给 AI 的文件和上下文范围，默认只发送当前页面相关代码。
- AI 用于复杂 JavaScript 逻辑，例如答题判断、计分、分支跳转、状态保存、媒体控制和反馈提示。
- AI 修改前显示自然语言说明、涉及文件、代码差异和风险提示。
- 用户确认前不写入项目文件。
- AI 修改后先在隔离预览中运行，失败时自动恢复到修改前版本。

**验收操作：**让 AI 为“点击按钮后判断选项并显示反馈”生成修改；查看差异，拒绝一次确认一次，再验证页面运行和撤销结果。

### 4. 完整版本历史

- 版本记录包含页面文件、CSS 覆盖规则、JS 修改和素材替换。
- 支持版本名称、时间、修改说明和涉及文件。
- 可以恢复单个文件，也可以恢复一次完整 AI 修改。
- 恢复前自动创建当前快照，恢复失败不破坏当前项目。
- 可以删除过期快照，但删除前必须二次确认。

### 5. 预览与差异检查

- 固定视口继续支持电脑、平板、手机竖屏、手机横屏。
- 支持刷新、运行测试和查看控制台错误。
- 显示源页面与预览页面的当前路径。
- AI 或交互配置应用前可以查看修改前后差异。
- 页面出现 JavaScript 错误时明确显示错误文件和行号。

## 三、第二版阶段顺序

### 第二版 A：动态元素完善

先完成动态元素的文字、样式、图片和背景图修改，建立稳定选择器和来源显示。

### 第二版 B：基础交互配置

已完成第一批：跳转页面、返回上一页、显示、隐藏、切换显示、切换样式、播放媒体、暂停媒体，并保证编辑模式不会触发原页面点击。下一批补充已存在交互的读取、清除和交互运行日志。

### 第二版 C：版本系统完善

已完成第一批：保存和素材替换前生成包含 HTML、CSS、JS、素材的完整项目快照；列表显示保存原因和快照范围；恢复前自动备份；支持带确认的版本删除。下一批补充版本名称、跨页面筛选和差异摘要。

### 第二版 D：AI 代码助手

最后接入用户自带 API，完成上下文选择、代码差异、隔离预览、确认应用和失败回滚。

## 四、第二版直接判定不合格的情况

- 动态元素只能预览，保存后刷新丢失。
- 修改动态按钮后破坏原有点击、跳转或答题逻辑。
- AI 未经用户确认直接改写项目文件。
- API 密钥出现在 HTML、CSS、JS、localStorage 或日志中。
- AI 生成错误后无法恢复到修改前版本。
- 编辑模式的点击误触发网页交互。
- 版本恢复只恢复界面，遗漏 CSS、JS 或素材文件。
- 页面路径、源码文件和预览页面对应不上。

## 五、第二版明确不做的内容

- 课程目录、章节管理和内容管理后台。
- 在线多人协作和云端项目。
- 自动生成完整课程内容。
- 自动兼容所有前端框架和压缩混淆代码。
- 不经用户确认的全项目自动重构。
- 模板市场、发布平台和运营数据后台。

## 六、第二版交付条件

第二版必须同时满足：

1. 第二版 A、B、C、D 四个阶段全部完成。
2. 真实 Vue/React/原生项目各至少通过一个动态元素编辑案例。
3. 至少完成 10 次交互修改、10 次撤销/重做和 3 次版本恢复测试。
4. AI 修改至少完成一次拒绝、一次确认应用和一次失败回滚。
5. `npm run typecheck`、`npm run build`、主进程语法检查通过。
6. 不出现静默覆盖、页面错写、密钥泄露和不可恢复的文件损坏。

第二版在全部条件通过前，不进入模板、目录、协作或发布功能开发。
