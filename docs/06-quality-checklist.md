# 质量与验收检查表

## 每个阶段都要检查

- [ ] 应用可以启动和正常退出。
- [ ] 错误有可理解提示，不出现静默失败。
- [ ] 未确认的修改不会覆盖源文件。
- [ ] 修改失败后可以恢复。
- [ ] 预览与保存后的项目结果一致。
- [ ] 关键操作有撤销路径。
- [ ] 不读取或写入用户未选择的目录。

## 第一条切片验收

- [ ] 可以打开包含 `index.html`、CSS、JS 和图片的示例主题单元。
- [ ] 图片、样式和脚本在预览中正确加载。
- [ ] 可以选中带 `data-editor-id` 的标题。
- [ ] 可以修改字号、文字、位置和宽高。
- [ ] 画布即时更新，且能切换三个视口。
- [ ] 点击取消不会写回文件。
- [ ] 点击保存后重新打开，修改仍然存在。
- [ ] 撤销和重做结果正确。
- [ ] 保存前源文件有可恢复快照。
- [ ] 未标识元素会提示暂不支持安全写回，不会猜测修改。

## AI 阶段验收

- [ ] 没有 API Key 时应用仍可完成手动编辑。
- [ ] API Key 不出现在项目文件和日志中。
- [ ] AI 结果包含修改说明和差异。
- [ ] 用户确认前不写回源文件。
- [ ] AI 修改后能在真实网页预览中运行。
- [ ] 代码错误、接口失败和用户拒绝都能恢复。
