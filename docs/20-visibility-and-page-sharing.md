# 默认状态、出现范围与跨网页应用

## 默认保持原状态

未设置出现范围的素材，继续服从课件自己的显示、隐藏和状态切换规则。未设置同步范围的属性，只在当前画面编辑；未修改的属性不写入。此前明确保存的范围设置会继续保留，不会在更新编辑器时被清空。

选择素材不会自动更改课件。跨网页区域默认不勾选目标网页、同步项或自动添加；切换到另一素材时重置这些选择。

## 出现范围

右侧“出现范围”可选：保持原状态、只在当前画面显示、在指定画面显示、本网页全部画面显示。

明确选择显示范围后，编辑器保存显示规则，并在课件脚本改变所选素材的 `hidden` 或 `display` 时重新应用。选择“保持原状态”后恢复跟随课件。修改出现范围属于一次布局修改，可撤销，点击顶部保存后写入 HTML。

“修改同步范围”仍分别控制位置、尺寸和其他样式。它不会自动改变出现范围，也不会自动修改其他 HTML。

## 跨网页应用

当前版本支持将图片应用到同一项目内的其他 HTML。

1. 勾选目标网页。
2. 勾选需要同步的位置、尺寸、图片内容或出现范围。
3. 若希望目标缺少对应公共素材时也能出现图片，勾选“缺少对应公共素材时，自动添加”。
4. 点击“保存当前修改并预览应用”，检查各网页是新增、更新还是跳过。
5. 点击应用按钮写入目标文件。

图片优先使用公共编号识别。目标网页尚未建立公共编号时，会按项目内相同图片源路径查找；只有找到唯一图片才会把它纳入同步，多个同图素材会跳过以免一起移动。跨网页面板中的“同步位置到全部网页”只同步位置；检查清单后应用即可。首次跨网页添加建立独立的公共素材实例；再次从同一来源应用，会更新对应公共实例，不重复创建。也可以从目标网页选择该公共图片继续同步。

跨网页位置以整个网页的主画布为基准，按画布宽高比例保存；同一素材在不同网页保持相同的整页相对位置，不随画面内部容器改变。设备范围沿用当前设备。指定状态按画面标识匹配，不推断不同课件中状态名称之间的对应关系。

只同步勾选项；新建实例需要完整图片和初始布局，因此新建时会使用来源图片及布局作为初值。

## 保存与恢复

跨网页应用前创建项目完整版本；预览后目标文件如果发生其他修改，会拒绝覆盖并要求重新预览。批量写入失败时恢复已经写入的文件。

一次批量应用对应一条撤销/重做记录。若目标文件在应用后又被独立修改，撤销不会覆盖新内容，可使用项目版本进行人工恢复。关闭编辑器后内存中的撤销记录不保留，完整项目版本仍在。

网页保存包含独立运行脚本，导出时无需安装编辑器。当前编辑器预览使用最新运行脚本，保留网页中已有的编辑数据。

本轮完成类型检查、前端构建和脚本语法编译；未运行自动测试或执行真实项目的跨网页批量写入。
