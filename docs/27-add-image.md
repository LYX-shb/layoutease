# 添加图片组件（2026-10-21）

画布工具栏增加“添加图片”。选择本地PNG/JPG/JPEG/GIF/WebP/SVG后，沿用已有素材复制接口导入assets/editor目录；原文件位置不作为课件的运行依赖。

图片加载成功后，以新增公共素材记录放入课件主画布中央，默认适当缩小并保留原比例。插入本身和后续位置、尺寸、显示修改共用布局快照、删除及撤销/重做/保存通道，保存前可撤销新组件。复制出的素材文件不会随撤销删除。

新图片默认自由调整角点、宽度和高度，支持右侧分别输入宽高。新图片的角点缩放选择写入公共素材记录freeResize，重开后仍可恢复。图片在主画布坐标中定位，沿用已有变换坐标的拖动和边缘尺寸控制。

识别到真实画面状态时，新图片默认仅当前画面显示，显示范围作为默认设备记录覆盖手机和电脑，之后可自行切换到指定画面或整页。没有画面状态的静态网页按当前HTML整页编辑，避免新增组件无法拖动或修改尺寸。不会自动添加到其他HTML。

导入期间保护页面切换和刷新，取消文件选择不添加组件，读图失败显示错误。素材导入事件不会造成预览监听立即重载、冲掉新组件。

通过CJS、内嵌预览桥接脚本、TypeScript编译和Vite构建。未添加或运行测试套件，未替用户选择图片或保存示例组件，未完成实际鼠标与真机交互验收。
