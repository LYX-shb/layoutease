# 华为手机与自定义预览

## 华为 Pura 70 Pro+ 横屏校准

华为型号按钮默认选择“横屏显示 · 网页 378 × 763”。这是为了还原用户确认的使用场景：手机实际横向持握，但课件在移动设备竖向网页视口中自行把 16:9 舞台旋转 90°。编辑器把整个 378 × 763 网页画面反向旋转到横向画布中，抵消课件的舞台旋转；页面动画也因此在编辑器里摆正。编辑器外框显示为约 763 × 378 CSS px。

“网页原生横屏 · 763 × 378”提供不旋转网页的直接横屏模式，供课件本来就按横向 viewport 排版时使用。普通“手机竖屏”预设则继续用于检查直立竖屏页面。

尺寸来自用户的手机截图：原图 1134 × 2560，白色状态栏和标题栏合计约 271 像素；旋转回横向后可用内容区域约 2289 × 1134，比例约 2.02。按 378 CSS px 的短边换算，横向画布约 763 × 378 CSS px。Pura 70 Pro+ 参数表列出面板分辨率 2844 × 1260；这是硬件像素，不等同于网页 CSS viewport，所以外层比例按用户截图和顶部白栏重新估算。[机型参数](https://detail.zol.com.cn/series/57/613/param_10859734_0_1.html)。微信导航、系统缩放和 WebView 设置可能造成差异。

## 其他预览设置

- 点击“用网页尺寸自定义”会把当前实际网页视口（包括旋转模式下的 378 × 763）复制到自定义尺寸。
- 顶部“自定义”允许输入 100–4096 的整数宽高，点击“应用尺寸”或回车生效；“横竖互换”交换输入的宽高并应用。
- 手机预设，以及短边不超过 500px 的自定义尺寸，会在页面脚本执行前模拟 Android 移动 UA、触控点和 UA Client Hints。桌面和平板预设不启用。
- 每个项目分别记住预设、华为方向及已应用的自定义宽高。输入尚未应用时不改变预览。
- 切换尺寸、方向或预设时如有未保存修改，沿用保存并切换／放弃并切换／取消流程。
- 缩放滑块只控制编辑器中的等比例显示。iframe 按网页视口尺寸运行；使用整数绘制倍率再等比例缩小显示，避免 Chromium 的非整数 zoom 让 iframe 内部少 1 像素。

## 验证与限制

- 预览单元测试、Electron 临时项目检查、TypeScript 检查和 Vite 生产构建通过后再发布安装程序。
- Electron 自查使用包含“移动 UA + 378 × 763 时舞台旋转 90°”的临时课件，检查页面内部视口、外层横向画布、画布与页面边界吻合，以及两次旋转方向相反。
- 尚未在用户真机的微信 WebView 实测；编辑器也不会模拟微信界面、华为浏览器引擎、系统字体、硬件像素密度或所有设备 API。若用户实际可视区域不同，可使用自定义宽高校准。

## 保存范围

新增预设与自定义尺寸沿用现有响应式规则，按实际网页视口宽度选择保存范围，提示显示在画布上方：不超过 500px、501–900px、901–1200px、超过 1200px 为默认样式。旋转预览仍按内部网页视口宽度 378px 选择手机竖屏保存范围。高度参与预览排版，不新增按高度或型号限定的保存规则。
