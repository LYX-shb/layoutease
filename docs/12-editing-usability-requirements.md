# 编辑操作与文件切换改进需求（已确认）

整理日期：2026-10-08

状态：用户于 2026-10-08 确认，本轮代码已实现并完成浏览器交互检查与自动检查；真实 Windows 安装版窗口及真实课件回归仍待验收。

## 1. 用户反馈

- 字号大小目前无法正常编辑，多次尝试修改仍无法完成。
- 画布中的元素太容易被拖动，普通点击容易造成误改。
- 最新交互要求：点击元素即可选中和修改属性，仅在需要拖动位置时确认启用拖动，不增加二次选中步骤。
- 希望自行调整元素大小，例如标题框的宽度和高度。
- 更换文件需要退出、重新打开，操作繁琐。

以上是实际使用反馈，现有文档中“已实现字号编辑”等记录不能代表这些操作已通过真实界面验收。具体故障原因在确认后排查。

## 2. 已确认的需求

### R1：修复字号编辑

- 正式选中文字元素后，属性面板显示当前有效字号。
- 字号输入框支持正常聚焦、输入、删除和替换数值，不应被预览刷新或选中状态更新打断。
- 输入合法字号并提交后，画布立即显示变化，同时标记为未保存；支持撤销、重做。
- 保存成功后，刷新及重新打开文件仍保留字号修改。
- 非文字元素或暂不支持编辑的对象应明确说明原因，避免出现看似可改但没有效果的输入框。

验收：对标题、正文和含文字的按钮分别修改字号；连续输入和替换数值可完成，预览、撤销、重做及保存后重开结果一致。覆盖普通 HTML 和动态生成的文字元素。

### R2：直接选中，仅拖动需要确认

- 编辑模式中，点击元素即可选中，显示边框和属性面板，直接修改字号、内容及其他属性，无需再次点击“选中”。
- 元素选中时默认禁止直接拖动位置，旁边提供“启用拖动”操作；用户确认后才允许拖动该元素。
- 启用拖动后可直接在元素上拖动，不要求使用专用移动手柄；达到合理距离阈值才开始移动，避免鼠标轻微抖动造成误改。
- 拖动完成后恢复位置锁定；下一次移动需重新启用拖动。此项已随本轮需求确认。
- 更换选中元素或点击空白区域时，取消之前的拖动授权；点击空白区域取消选中。
- 启用拖动本身不修改元素，也不产生未保存记录；控制按钮保持可见，不触发原网页交互。
- 测试模式继续运行网页本身的交互，不显示编辑控件。

验收：单击元素后即可编辑属性；未启用拖动时按住移动不会改变位置；启用后可拖动，支持撤销、重做和保存；拖动结束及更换目标后不会沿用之前的拖动授权。

### R4：直接调节元素大小

- 选中可调整大小的元素后，显示边框和边角缩放控制点，可以拖动控制点调整宽度、高度，例如拉宽或拉高标题框。
- 右侧同时提供宽度、高度输入框，支持精确输入，且与画布上的调整结果同步。
- 调整大小不需要先启用位置拖动；缩放控制点与位置移动操作清晰区分，不能误触发移动。
- 标题框的宽高与文字字号分别控制；改变框大小不自动改变字号，文字按布局换行。
- 大小变化实时预览，支持撤销、重做；保存后刷新和重新打开仍保留。
- 图片默认保持比例，文本框允许独立调整宽高；不支持调整的对象应说明原因。

验收：标题框可通过边角控制点和宽高输入框调整大小，文字正常显示或换行；字号不随框大小自动改变。图片缩放保持比例。大小修改可以撤销、重做、保存并重新打开验证。

### R3：应用内打开与切换文件

- 无需退出软件，即可打开另一个文件或切换到另一个项目。
- 同一项目内，使用页面列表直接切换已有 HTML 页面，无需重新选择项目文件夹。
- 工具栏提供清晰的“打开文件”和“切换项目”入口，显示当前文件名与路径。
- 打开 HTML 文件时使用其所属项目的资源上下文，保证关联 CSS、JavaScript 和图片正常加载；具体项目目录识别方案在实现时确定。
- 当前文件有未保存修改时，切换前提供“保存并切换”“放弃修改并切换”“取消”选项；保存失败时停留在当前文件，保留修改。
- 切换完成后清除旧页面的选中、拖动授权和属性状态，撤销记录不能作用到另一文件；预览、路径和保存目标必须一致。

验收：在同一项目的两个页面及两个不同项目之间往返切换，全程无需退出软件；覆盖已保存、未保存、取消切换和保存失败场景，不能丢失修改或写错文件。

## 3. 已确认的交互理解

1. 点击元素直接编辑，仅移动位置前点击“启用拖动”；不再采用二次选中或专用移动手柄方案。
2. 默认一次拖动结束即恢复锁定，避免后续误拖。
3. 元素大小通过边角控制点或宽高输入框调整，标题框大小与字号分别控制。
4. “切换文件”按同一项目的页面切换，以及应用内打开其他 HTML 文件或项目理解；本次不扩展为源码编辑器或多标签工作区。

## 5. 本轮实现与验证记录

- 修复预览桥接中的 CSS 属性名转换（`fontSize` → `font-size`），字号等样式使用有效 CSS 属性应用。
- 属性数值可以直接输入数字（默认 px），按 Enter 或离开输入框应用，输入期间不逐字回写预览；非法值显示原因。
- 点击直接选中；位置默认锁定，点击元素旁的“启用拖动”后才允许移动，拖动结束自动锁定。
