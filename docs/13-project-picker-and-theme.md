# 启动直达编辑、项目选择与黑白主题

确认与实现日期：2026-10-08

## 用户需求

- 启动软件直接进入编辑页面，不再经过欢迎页。
- 自动发现电脑里的网页项目，像参考图一样从“当前项目”下拉列表自由选择，显示名称和路径。
- 未自动识别的项目可手动导入。
- 编辑器颜色仅提供“白色”“黑色”两种选项。

## 实现行为

1. 无项目时仍显示编辑工作区、项目选择器和主题按钮，中间提示选择项目或手动导入；不显示误导性的已打开文件路径。
2. 启动后台发现本地 HTML 项目：最近打开的项目优先，扫描桌面、文档、下载，以及当前磁盘和 Windows C/D/E/F 盘的浅层目录。目录向下最多两层，总计最多检查 400 个目录；忽略隐藏目录、依赖、系统目录及符号链接。不能将此功能表述为完整全盘搜索。
3. 发现含 HTML/HTM 文件的文件夹后加入列表，优先使用 index.html/index.htm，否则使用该目录的首个 HTML 页面；项目内部的其他页面继续从左侧页面列表选择。
4. 顶部提供“浏览文件夹”“导入 HTML”“重新扫描”；导入是打开本地文件，不上传到网络。手动选择文件夹无需一定包含 index.html，存在其他 HTML 页面也可打开。
5. 本机用户数据目录中的 recent-projects.json 保存最多 30 个最近项目。重启自动恢复最近仍可读取的项目；手动导入的项目加入选择列表。
6. 项目下拉切换、浏览或导入沿用未保存修改的保存/放弃/取消流程。项目丢失或不可读时显示原因，保留原工作区。
7. 白色/黑色仅影响编辑器工具栏、侧栏、输入框、弹窗及工作区；课件 iframe 的原有颜色保持不变。主题选择保存在本机并在重启后恢复。
8. 窗口宽度不足时工具栏换行，侧栏与画布各自滚动。
9. 预览在保持网页原始宽高比和内部布局尺寸的前提下，自动放大到可用编辑空间；提供缩小/放大、50%–200% 缩放滑块及“适合窗口”恢复自动适配。编辑器通过页面重绘应用缩放，避免先前整体变换引起的文字和图像模糊。该缩放只用于编辑器中的预览展示，不写入网页样式或项目文件。

## 验证记录

- 12 项自动测试通过：新增本地发现、index 优先、HTM 识别、最近项目恢复、依赖/隐藏目录排除、扫描预算、越界入口拒绝、手动导入记录以及已登记项目键打开检查。
- 浏览器使用临时课件和模拟桌面 API，检查无欢迎页直接进入工作区、项目下拉选择、手动导入加入列表、刷新后恢复项目及主题、未保存切换保护和黑白界面显示。
- 黑白主题切换前后，临时课件背景色均保持 rgb(246, 249, 254)。
- 实际只读扫描 D 盘发现 12 个候选项目，包括放大镜、扩句作文、时间、显微镜、望远镜和相机；扫描未触及目录上限。候选识别不等于所有课件运行逻辑均已验收。
- TypeScript 检查、主进程/preload 语法检查和前端生产构建通过。
- 桌面文件对话框和真实 Windows 安装版启动仍需本机实际验收；本轮未重新生成安装包。
