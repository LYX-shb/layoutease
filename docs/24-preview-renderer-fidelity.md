# 编辑器预览遵循课件自身布局（2026-10-20）

## 原因与修改

预览协议此前移除了 HTML 中保存的布局运行脚本，并注入编辑器最新版。同一份课件可能因此在独立打开和编辑器打开时使用不同的布局规则。

现在保留原脚本，由它负责绘制布局。编辑器增加控制接口，修改后通过原脚本的 restore/getStyles 接口同步，不另建一个布局观察器。打开、选择素材、切换编辑/交互模式不会升级课件的绘制规则。普通布局保存继续保留原运行脚本；首次添加布局数据的课件才写入当前运行脚本。

编辑范围只决定新修改写入哪个设备范围，不再覆盖预览的设备检测。这样，普通桌面浏览器的窄窗口不会因为保存到旧的 mobileLandscape 范围而额外启用 phone 设置。

画布适合窗口和手动缩放统一使用外层 transform 等比例显示，移除作用于 iframe 的 CSS zoom。保留用户选择的网页宽高，以及 P70 已有的整页旋转显示选项。

本次未改写任何课件文件、手机布局数据或服务器文件。新版编辑器保留各设备自身的响应式差异。
