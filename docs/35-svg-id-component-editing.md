# SVG ID 组件编辑修复（0.1.10，2026-10-29）

11.2 的导出图层使用 `g#n-1-*`，动态间隔卡使用带按钮语义的 SVG 组。旧版仅认识 `data-node`，点击卡片时选中了整个 SVG。已在真实课件副本上复现该错误。

修复为从场景中的组 ID 和按钮组识别独立对象；按钮中的图片、数字与装饰保持为一个可移动对象。保留小 SVG 图标的整体选择。框选同样识别这些组，位置使用现有父级坐标换算；尺寸输入与控制点可对 SVG 组生成可撤销的视觉缩放。
