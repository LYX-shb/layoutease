# 分阶段执行计划

每个阶段都必须有可运行产物和验收记录。阶段未通过前，不进入下一阶段。

## 阶段 0：工程准备

目标：从空仓库建立可启动的 Windows 桌面应用骨架和文档基线。

产物：Electron + React + TypeScript + Vite 应用骨架、应用启动页、项目目录约定、基础日志、最小检查命令。

验收：应用可启动；关闭和重新打开不丢失；错误能记录；文档路径可找到。

## 阶段 1：单主题单元导入与预览

目标：打开一个本地 HTML/CSS/JS 项目，并在隔离预览区运行。

产物：打开项目、选择入口 HTML、显示网页、基础刷新、文件读取错误提示。

验收：能打开示例项目；相对图片、CSS 和 JS 正常加载；预览不能访问桌面 Node 能力；未知项目不会被覆盖。

## 阶段 2：手动微调闭环

目标：完成最常用的字体、文字、位置和大小调整。

产物：`data-editor-id` 识别、元素选中、属性面板、拖拽微调、草稿状态、确认保存。

验收：修改标题字号和位置后，预览立即更新；确认保存后重新打开仍正确；找不到标识时明确提示而不是猜写。

## 阶段 3：素材与响应式预览

目标：替换素材并在三种设备视口检查效果。

产物：图片/图标/背景替换、素材引用更新、电脑/平板/手机预设、超出视口提示。

验收：替换素材不破坏相对路径；三种视口可以独立预览；原素材可通过撤销恢复。

## 阶段 4：历史与基础页面能力

目标：让编辑过程可逆，并支持已有项目中的多个页面。

产物：撤销、重做、保存前快照、版本列表、恢复版本、已有多 HTML 页面切换。

验收：连续 10 次编辑可正确撤销和重做；恢复旧版本后项目可重新预览；恢复失败不损坏当前项目。

## 阶段 5：基础交互编辑

目标：支持常见网页学习交互的可视化设置。

产物：页面跳转、返回、弹窗、显示隐藏、媒体控制的基础配置。

验收：每类动作都有运行预览；配置写回后刷新仍有效；原有未识别 JS 不被删除。

## 阶段 6：用户 API 与 AI 代码助手

目标：让 AI 帮助编写复杂 JavaScript 逻辑。

产物：API 设置、连通性测试、项目上下文选择、代码补丁、差异查看、预览、应用、失败回滚。

验收：未配置 API 时普通编辑可用；AI 不直接覆盖文件；用户确认前不写回；生成错误时可恢复到应用前版本。

## 阶段推进规则

- 一个阶段只解决该阶段目标，不以“顺便”方式扩展模板、目录、发布或协作功能。
- 每阶段完成后更新 [06-quality-checklist.md](./06-quality-checklist.md) 的结果。
- 出现数据损坏、无法恢复、预览越权或静默覆盖时，立即停止扩展功能，优先修复。
