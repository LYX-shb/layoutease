# 0.1.7 SVG 内部素材选择修复（2026-10-26）

## 原因

“10.1”课件的场景由一个 SVG 容纳多个带 `data-node` 的独立素材。编辑器过去会把命中的所有 SVG 子元素提升为整张 SVG；随后覆盖整个选区的拖动框又会拦住普通单击，导致持续选中整张画面。该课件也没有旧版适配器支持的公开画面状态接口，默认的画面隔离保护会阻止修改。

## 修改

- 多素材 SVG 根据作者提供的 `data-node` 选中内部对象；普通 SVG 图标继续整体选择。保存使用 SVG 范围内唯一的节点标记，避免依赖外围分组的兄弟顺序。
- 在选框内单击可以切换到下方素材；拖动仍移动当前单选或多选。4 像素以内的抖动视为点击，拖动条仍可直接操作。
- SVG 对象拖动通过 `getScreenCTM` 换算父坐标，尺寸使用独立可还原的缩放，不改变原 SVG 图形和定位属性。
- 对 `FIGMA.scenes` 明确列出的 SVG 画面进行内容匹配，保留现有课件画面标记和公开状态 API 的优先级。未知内容不沿用旧画面标记。画面识别和尺寸运行逻辑随首次保存写入 HTML。

## 验证

61 项 Node 测试、TypeScript 编译、Vite 构建通过。“10.1”副本通过 19 项 Electron 检查，包括普通选择、原生鼠标选择、逃离整页选框、准确拖动、尺寸改变、保存重开、切换画面隔离，以及图片、背景、图标、裁切和交互回归。测试使用临时课件和独立配置目录，未改动 `D:/10.1`。

安装包为 `release/Theme-Unit-Editor-0.1.7-Setup.exe`。已运行的 0.1.6 需要安装新版并重新打开后才会使用修复。

本次没有把图片中文字、轮廓路径或 canvas 自动转为可编辑文字，也未扩展为任意 SVG 的逐路径编辑。已有课件保存的旧布局运行器继续保留其既有绘制规则。
