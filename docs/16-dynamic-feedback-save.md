# 动态答题提示保存修复（2026-10-13）

用户反馈：移动错误提示避免与底部算式重叠，保存后进入测试和上传服务器查看，位置又恢复原样。

## 原因与修复

实际文件 `D:\一共总共\index.html` 已保存 `translate(3px, -17px)`，但规则将提示容器定位为 `div#feedback...:nth-child(13)`。当前课件中它是第 14 个子元素，规则没有命中。提示图片由答题逻辑重新创建，所以预览中的临时内联修改也不能保留。

- 新生成的选择器以唯一的 HTML ID 为锚点；图片优先用可访问文字标识，不把无关兄弟元素的序号写进路径。
- 打开项目时修复旧版编辑器生成的动态样式及内容定位，保留正确/错误状态和设备范围，修复前创建完整项目快照。
- 再次编辑时复用已命中的保存规则，使旧规则能够被更新，而非新增一个被旧规则压过的定位。
- 自动编号跳过已保存的动态样式编号，避免刷新后给另一张图片分配相同编号并覆盖原规则。
- 将运行时图片匹配到静态 HTML 前核对图片来源，避免仅因序号相同而把修改写到另一张素材。

排查时已修复本地真实课件的旧规则，原位置数值及设备范围保留。修改前原文件备份在系统临时目录 `editor-selector-repair-TpAyjU\index.html`。后续升级编辑器并重新打开已有项目时，会自动备份并修复同类旧规则。

验证期间原课件的 HTML/CSS 另有更新：旧动态样式块被移除，提示在外部 CSS 中使用统一中心布局。已保留这些更新，并重新验证最新文件，未把旧位移重新写入新布局。
