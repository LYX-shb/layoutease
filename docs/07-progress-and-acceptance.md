## 已完成内容

- Windows 桌面窗口和极简启动页。
- 选择本地主题单元文件夹。
- 检查项目入口 `index.html`。
- 使用受控的 `editor-project://` 通道加载网页、样式、脚本和素材。
- 电脑、平板、手机竖屏、手机横屏四种预览尺寸切换。
- 读取带有 `data-editor-id` 的元素。
- 对没有标识的普通网页元素进行临时自动识别，允许先在预览中拖动查看效果。
- 在预览中点击元素并显示选中边框。
- 拖动选中元素进行临时移动。
- 撤销和重做临时移动。
- 修改选中元素的文字和字号，并实时反映在预览中。
- 修改选中元素的宽度、高度、颜色、外边距和内边距，并实时反映在预览中。
- 保存前在应用本地创建快照，再将文字、字号、位置和常用样式写回当前 HTML 页面。
- 示例项目位于 `examples/theme-unit`。
- TypeScript 检查和前端构建已通过。
- 编辑模式和测试模式切换；测试模式可以运行原网页按钮和页面跳转。
- 扫描已有项目中的多个 HTML 页面，并在左侧切换预览页面。
- 普通元素保存时由编辑器自动根据标签、文字、class 或图片来源定位，并为当前元素建立稳定标识；用户不需要手动修改 HTML。
- 选中图片元素后可以选择新图片，复制到项目的 `assets/editor` 目录并在预览中替换。
- 选中包含图片的按钮或卡片后可以替换其中的第一张图片，移动仍作用于整个外层元素，保存会写回对应的嵌套 `<img>`。
- 非电脑视口的样式保存为当前页面的响应式 CSS 规则，手机竖屏和横屏方向保存到项目设置。
- 版本入口可以查看当前页面的保存快照并恢复选定版本；恢复前再次创建当前版本快照。
- 保存和素材替换前会创建完整项目快照，恢复时同步恢复 HTML、CSS、JS、素材和编辑器设置；版本列表显示保存原因和快照范围，删除需要确认。

## 当前版本如何验收

1. 在项目根目录运行 `npm run dev`。
2. 点击“打开主题单元”。
3. 选择 `examples/theme-unit` 文件夹。
4. 在网页预览中按住标题或按钮拖动。
5. 确认元素出现蓝色边框并移动。
6. 点击“撤销”和“重做”，确认位置可以往返恢复。
7. 切换电脑、平板、手机竖屏、手机横屏，确认预览画布尺寸变化。
8. 选中标题，在右侧修改文字或字号，确认预览立即变化。
9. 选中图片，点击“替换图片”，选择新图片，确认预览立即变化。
10. 点击“保存”，关闭并重新打开项目，确认修改仍然存在。
11. 切换手机竖屏和横屏，分别修改一个元素并保存，刷新后确认对应视口仍能看到各自样式。
12. 点击“版本”，确认能看到保存记录，恢复旧版本后页面可以重新加载。
13. 选中包含图片的声音、返回或下一题按钮，点击“替换按钮图片”，保存后关闭并重新打开项目，确认按钮图片和原有点击逻辑都保留。
14. 在编辑模式中点击带有原网页逻辑的按钮，确认只选中元素，不跳页、不弹窗；切换到测试模式后确认原网页逻辑可以运行。
15. 在右侧“基础交互”中为按钮配置跳转或显示/隐藏，保存后切换页面或刷新，确认配置仍在并且只影响当前页面。
16. 连续保存一次页面、样式和素材修改，打开“版本”确认显示“项目全部文件”，恢复后确认 HTML、CSS、JS 和素材一起回到快照状态。

## 当前限制

- 保存定位采用唯一匹配保护；如果同类元素无法唯一判断，编辑器会拒绝写入并提示原因，避免误改其他元素。
- 当前素材替换先支持图片元素；背景图和音视频素材后续加入。
- 多页面目前只支持读取和切换，尚未提供页面新增、删除和排序；测试模式可运行页面自身的下一页逻辑。
- 基础交互配置第一批已接入：跳转、返回、显示/隐藏、切换样式、播放/暂停媒体；AI 尚未接入。
