# 组合内部位置修复（2026-10-20）

## 原因

增加1保存的13个组合成员中，10个指向图片，3个指向外层按钮。按钮中的图片仍有各画面不同的桌面位置记录，手机继承后会在组合位置固定时继续移动。

## 修改

- 单张图片的按钮、链接及带稳定对象编号的容器，在组合时统一绑定完整对象；旧组合在运行时也按完整对象解析。
- 组合记录保存内部图片的相对位移及必要的变换，强制组合生效时覆盖旧内部位置；保留原始记录，退出组合范围后仍使用原布局。
- 新组合及重新移动的组合按图片的可见外框采集位置，同时移动完整对象，使点击区域跟随图片。
- 单独将位置设为当前或指定画面时，仅为这个成员增加对应画面的例外；保留此刻外层位置，不解除其他成员及其他画面的组合约束。
- 内部偏移在整体拖动期间继续固定；组拖动产生一份布局历史，原有撤销、重做及跨网页保存通道继续使用完整快照。
- 为旧版不支持独立translate的浏览器，记录已应用的位移，防止组合补偿计算重复叠加。
