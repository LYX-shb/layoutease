# 点击后定格与编辑暂停（2026-10-22，0.1.4）

## 使用

- “编辑”会暂停当前预览中的课件定时任务、动画和音视频，编辑器的选择、拖动、属性修改和保存继续工作。
- 点击“点击后定格”，再点击课件答案或按钮，允许这次交互执行，暂停延时任务，保留点击产生的同步、微任务及前两帧更新，随后自动切换到编辑。
- 等待点击时再次点击“等待点击…”可取消并暂停当前画面；点击“测试”会恢复运行。
- 恢复按各定时任务的剩余时间继续，重复任务不会补跑暂停期间漏掉的次数。
- 已经跳过的状态需要重新触发；此功能不会倒退 JavaScript 内存或恢复过去的页面。

## 实现范围

`electron/preview-playback.cjs` 仅在 `editor-project` 预览响应中前置注入，不写入课件。它接管课件的 timeout、interval 和 rAF，记录剩余时间；编辑桥使用保留的原生计时接口，不受课件暂停影响。CSS/WAAPI 动画与 HTML audio/video 仅恢复暂停前正在播放或暂停中请求播放的实例。

“点击后定格”在点击捕获阶段阻止延时任务前进，保留该次事件的正常传播和微任务，并为事件创建的 rAF 留出两帧用于绘制反馈。没有保存 DOM 快照或重建课件。未尝试暂停任意网络/Promise 回调、Worker、自定义调度器或 Web Audio；这些驱动的课件需要单独适配。跨文档跳转不属于当前画面定格的范围。

前端沿用现有按钮样式；预览控制区较窄时工具栏分行，防止按钮与设备下拉框重叠。AI 隔离预览仍按测试模式运行。捕获的画面不会被外部文件变更自动刷新覆盖，用户仍可主动读取最新文件。
