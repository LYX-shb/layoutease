# 图片尺寸与比例

右侧“尺寸与间距”提供“角点等比缩放”。图片角点默认等比，普通元素角点默认自由调整。边缘控制点和宽高输入框始终独立调整，不受此开关影响。开关只改变本次编辑方式，不会直接修改网页；实际尺寸调整仍遵守当前设备和尺寸应用范围，并随保存写入网页。

- 角点等比开启时，角点按拖动开始时的当前宽高比例连续调整，不在第一次移动时自动改成另一种比例。若需要纠正已变形的图片，先点击“恢复原图比例”。
- 宽度边点只改变宽度，高度边点只改变高度。宽高输入框也始终独立修改。关闭“角点等比缩放”后，角点自由调整宽高。
- “恢复原图比例”保持当前宽度，按原图尺寸计算高度，同时开启角点等比。图片尚未加载完成时此按钮不可用。
- 角点锁定缩放将鼠标位移投影到固定比例方向，避免中途切换主轴造成跳动；按住 Alt 再拖控制点可临时自由拉伸。

## 跟随鼠标

- 手机旋转画布下，控制点和鼠标位移共用课件局部坐标，宽度、高度方向一致。
- 手势期间保留控制点，只按浏览器绘制帧更新位置，放开鼠标后刷新属性面板和记录一次撤销。
- 宽高成批应用，保留小数位；放开时补上最后一个鼠标位置。退回拖动起点也能恢复初始尺寸或位置。
- 默认自由移动，按住 Shift 才吸附对齐。手势期间暂停所选元素的过渡与动画，结束后恢复。

整张 PNG 中的文字、圆角和边框会随图片一起拉伸。若需要改变提示框形状但保持文字大小和圆角形状，需要将文字与背景拆分，或制作可平铺/九宫格背景；比例锁定本身无法拆分位图内容。

本次定位到蜜蜂课件提示条素材 `image 169.png` 原图为 877 × 117，而初始课件配置为 800 × 72，导致横向比例偏大。编辑器原先又强制图片按当前比例联动缩放，所以无法独立更改宽高，也无法通过等比拖动恢复原图比例。

本功能修改了预览桥接脚本，首次启用需要重开新版桌面编辑器。之后保存并刷新课件预览即可。
