# LayoutEase 命名与兼容约定

- 产品名称：**LayoutEase**。
- 英文标语：*Drag. Adjust. Save.*
- 中文说明：可视化拖动与调整网页组件，让页面修改更简单。
- GitHub 仓库：`LYX-shb/layoutease`。
- 后续构建的安装包名：`LayoutEase-<版本号>-Setup.exe`。

名称用于窗口标题、页面标题、工具栏、打包产品名、快捷方式和对外文档。已有 0.1.10 发布包属于更名前的历史产物，继续保留原始文件名与内容。

为兼容既有安装和保存记录，内部 npm 包名 `interactive-learning-editor`、应用 ID `com.themeunit.editor`、预览消息来源、存储键和 HTML 保存标记沿用既有标识。这些标识不等于对外产品名；维护时不能只为替换名称而批量改写，以免旧项目记录和应用数据失联。

本次统一名称不改变版本号，也不重新发布或安装桌面二进制文件。后续发布新版本时按新的打包名称生成安装包。
